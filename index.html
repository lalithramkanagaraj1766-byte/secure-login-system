Hashed passwords

Passwords are salted and hashed with scrypt through Werkzeug. The original password is never stored.

SQL injection defence

Every database query is parameterized, so user input is treated as data and never as SQL code.

Protected sessions

HttpOnly, SameSite cookies, a 30-minute idle timeout and a fully cleared session on logout.

Attack prevention

CSRF tokens on every form, login rate limiting and generic error messages that reveal nothing.
